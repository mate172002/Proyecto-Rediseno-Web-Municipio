# Prototipo Frontend - Municipio de Loja

## Descripción
Este proyecto es un prototipo académico del frontend para la página web del Municipio de Loja. Se ha diseñado buscando modernizar la experiencia digital de los ciudadanos, con una interfaz limpia, accesible y completamente adaptable a dispositivos móviles.

> **Aviso Importante**: Este es un **prototipo académico no oficial**, desarrollado exclusivamente con fines educativos. No representa un portal gubernamental real, no procesa trámites reales y los datos mostrados son simulados.

## Objetivo
Modernizar la experiencia digital ciudadana para facilitar la búsqueda de servicios municipales, trámites, noticias, información institucional y medios de contacto mediante una interfaz moderna, profesional y fácil de usar.

## Tecnologías Utilizadas
- **React 19**
- **Vite**
- **TypeScript**
- **Tailwind CSS v4**
- **React Router v7**
- **Lucide React** (Iconos)

## Funcionalidades
- ✅ Navegación fluida con React Router (SPA).
- ✅ Diseño 100% responsive (Mobile First).
- ✅ Catálogo interactivo de trámites y servicios.
- ✅ Buscador y filtros por categorías en servicios y noticias.
- ✅ Formulario de contacto con validaciones en el cliente.
- ✅ Identidad visual moderna basada en los colores de la ciudad de Loja.
- ✅ Accesibilidad básica y estilos consistentes.

## Requisitos Previos
- Node.js (versión 18 o superior)
- npm o yarn

## Instalación

1. Clona el repositorio o descarga los archivos.
2. Abre una terminal en la raíz del proyecto.
3. Instala las dependencias:
   ```bash
   npm install
   ```

## Comandos Disponibles

Para levantar el servidor de desarrollo local:
```bash
npm run dev
```

Para compilar el proyecto para producción:
```bash
npm run build
```

Para previsualizar la compilación:
```bash
npm run preview
```

## Estructura de Carpetas

```text
src/
├── assets/       # Imágenes y recursos estáticos
├── components/   # Componentes UI reutilizables (Header, Cards, etc.)
├── data/         # Datos simulados (servicios, noticias, etc.)
├── layouts/      # Estructuras principales de página
├── pages/        # Vistas completas de la aplicación
├── types/        # Interfaces de TypeScript
├── utils/        # Funciones utilitarias
├── App.tsx       # Configuración principal y enrutamiento
├── index.css     # Estilos globales y configuración de Tailwind
└── main.tsx      # Punto de entrada de la aplicación
```
